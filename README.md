# 천안시 청년정책 2026 · 웹 프레젠테이션

원본 10장 PPTX를 고해상도 WebP로 변환해 원본 화면을 보존했습니다. 프레젠테이션 콘텐츠는 `slides.json`에 저장됩니다.

## GitHub Pages 배포

1. 새 GitHub 저장소를 만들고 이 폴더의 **내용물** (`index.html`, `assets/`, `slides.json` 등)을 저장소 루트에 업로드합니다.
2. GitHub 저장소의 Settings → Pages에서 **Deploy from a branch**, Branch `main`, Folder `/(root)`를 선택합니다.
3. 게시된 주소에서 열면 됩니다. 서버/DB/CDN 불필요.

## 조작

- 방향키 ←/→ 또는 ↑/↓, PageUp/PageDown, Space: 이동
- Home/End: 첫/마지막 슬라이드, F: 전체화면, M: 목차, I: 슬라이드 정보, P: 자동 재생
- 화면 좌우 버튼 또는 터치 스와이프, 데스크톱 휠 스크롤 지원
- 상단 목차 메뉴로 슬라이드 바로가기, 하단 진행 막대에서 임의 슬라이드 선택
- 소스 PPTX: `source-presentation.pptx`

## 자료 유의

2025년 분야별 예산과 2026년 예산 총액을 혼동하지 마세요. 원본의 계획 수치를 실적이라고 표현하지 않았습니다. 슬라이드 10의 방향은 확정 정책이 아닌 제안입니다.

## 구현

순수 HTML/CSS/JS, 모든 이미지 로컬 상대경로, 웹 폰트 및 외부 라이브러리 없음. 이미지 슬라이드 방식으로 시각적 충실도를 우선합니다. 슬라이드의 개별 도형/차트 데이터는 웹에서 직접 편집되지 않으며, 정보 패널에 접근 가능한 텍스트 정보를 제공합니다.
